title: "Quickstart"
description: "Run Stockël locally using Docker Compose."
---

This guide takes you from a fresh checkout to a running local instance. The entire stack — Next.js app, PostgreSQL database, and Prisma migrations — runs inside Docker, so you do not need Node.js or PostgreSQL installed on your machine.

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/ChrisOmar43/stockel.git
    cd stockel
    ```
  </Step>

  <Step title="Install Docker Desktop">
    Docker Desktop bundles the Docker Engine and Docker Compose. Download the installer for your operating system:

    - **Windows and macOS** — [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop)
    - **Linux** — [docs.docker.com/desktop/install/linux-install](https://docs.docker.com/desktop/install/linux-install/)

    After installation, start Docker Desktop and wait for the engine indicator to turn green before continuing.
  </Step>

  <Step title="Create the environment file">
    Create a `.env` file in the project root. You can copy the example file if one exists, or create it manually:

    ```bash
    cp .env.example .env
    ```

    Alternatively, create `.env` with the following content:

    ```env .env
    # Database connection — must match the db service credentials below
    DATABASE_URL=postgresql://stockel_user:password123@db:5432/stockel_db

    # PostgreSQL service credentials
    POSTGRES_USER=stockel_user
    POSTGRES_PASSWORD=password123
    POSTGRES_DB=stockel_db

    # NextAuth / JWT
    NEXTAUTH_SECRET=local-dev-secret-key-change-this
    NEXTAUTH_URL=http://localhost:3000

    # App URL (used in emails and links)
    NEXT_PUBLIC_APP_URL=http://localhost:3000

    # Google reCAPTCHA (required for the login/register forms)
    NEXT_PUBLIC_RECAPTCHA_SITE_KEY=your-recaptcha-site-key
    RECAPTCHA_SECRET_KEY=your-recaptcha-secret-key

    # SMTP (required for email verification and password reset)
    SMTP_HOST=smtp.example.com
    SMTP_PORT=587
    SMTP_SECURE=false
    SMTP_USER=you@example.com
    SMTP_PASS=your-smtp-password
    EMAIL_FROM=no-reply@example.com

    # OpenAI (required for the AI assistant)
    OPENAI_API_KEY=sk-...
    OPENAI_MODEL=gpt-4o
    ```

    <Warning>
      Never commit `.env` to version control. It contains credentials and secrets. The repository's `.gitignore` should already exclude it — verify this before your first commit.
    </Warning>

    <Note>
      The `DATABASE_URL` hostname must be `db` (not `localhost`) because it refers to the `db` service inside the Docker network. Changing it to `localhost` will cause the app container to fail to connect.
    </Note>
  </Step>

  <Step title="Start the containers">
    Run the following command from the project root:

    ```bash
    docker-compose up -d
    ```

    This builds the Next.js image (using the multi-stage `Dockerfile`) and starts three containers:

    | Container | Image | Purpose |
    |---|---|---|
    | `stockel_app` | Built from `./Dockerfile` | Next.js application on port 3000 |
    | `stockel_db` | `postgres:15` | PostgreSQL database on port 5432 |

    <Note>
      The `nginx` and `certbot` services are scoped to the `prod` profile and do not start in the default local configuration.
    </Note>

    <Tip>
      If the build fails or you want to follow progress in real time, run without the `-d` flag: `docker-compose up`. To watch logs after starting in detached mode, use `docker-compose logs app -f`.
    </Tip>
  </Step>

  <Step title="Run database migrations">
    Once the containers are running, apply the Prisma migrations to create the database schema:

    ```bash
    docker-compose exec app npx prisma migrate dev
    ```

    This command runs inside the `stockel_app` container and creates all tables defined in `prisma/schema.prisma`. You only need to run this once on a fresh database, or again whenever new migration files are added.

    <Note>
      If you see a connection error, wait 10–15 seconds for the PostgreSQL container to finish initializing, then retry.
    </Note>
  </Step>

  <Step title="Open the app">
    Navigate to [http://localhost:3000](http://localhost:3000) in your browser. You should see the Stockël landing page with **Iniciar sesión** and **Registrarse** buttons in the top-right corner.

    Register your first account to get started.
  </Step>
</Steps>

## Useful Docker commands

```bash
# Check running containers and their status
docker-compose ps

# Follow app logs in real time
docker-compose logs app -f

# Open a shell inside the app container
docker-compose exec app sh

# Stop all containers without removing volumes
docker-compose down

# Rebuild and restart (after code changes)
docker-compose up -d --build

# Apply migrations in an already-running container
docker-compose exec app npx prisma migrate deploy
```

## Available npm scripts

These scripts run inside the container but are listed here for reference:

```bash
npm run dev      # Start Next.js in development mode
npm run build    # Produce a production build
npm start        # Start the production server
npm run lint     # Run ESLint
```
