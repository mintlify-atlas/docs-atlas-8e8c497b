## What is Stockël?

Stockël is a full-stack inventory management system designed for businesses operating across multiple store locations. It provides a unified platform to manage products, track stock movements, process purchase orders, record sales, and monitor financial health — all with role-based access control so each team member sees only what they need.

## Technology stack

Stockël is built on a modern, production-ready stack:

| Layer | Technology |
|---|---|
| Frontend | Next.js 16 (App Router), React 19, TailwindCSS 4 |
| Backend | Next.js API Routes, Prisma ORM |
| Database | PostgreSQL 15 |
| Authentication | NextAuth.js v4, JWT, bcrypt |
| AI | LangChain + OpenAI |
| DevOps | Docker, Docker Compose, GitHub Actions |

## Getting started

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/ChrisOmar43/stockel.git
    cd stockel
    ```
  </Step>
  <Step title="Configure environment">
    Create a `.env` file with your database and auth credentials. See the [quickstart guide](/quickstart) for all required variables.
  </Step>
  <Step title="Start with Docker">
    ```bash
    docker-compose up -d
    ```
    The application will be available at `http://localhost:3000`.
  </Step>
  <Step title="Run migrations">
    ```bash
    docker-compose exec app npx prisma migrate dev
    ```
  </Step>
</Steps>

<Note>
  Stockël uses Docker for both local development and production. Make sure Docker Desktop is installed before proceeding.
</Note>
